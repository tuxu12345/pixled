# 验证记录 · 2026-09-14

环境：Windows / Node.js 24.16.0 / Chromium 浏览器。

- `npm test`：12/12 通过，包括全部三关按正常物理规则自动完成、最终首领门锁、二段跳、平台落地、伤害保护和掉落重生。
- 实际键盘：开始、方向移动、J 连射、空格跳跃、暂停；角色前进，暂停后的画面逐字节保持不变。
- 分辨率：96×48、128×64、192×96 切换，原生缓冲和显示尺寸同步。
- 设置：LED / 纯净像素、亮度、辉光、扫描线和音效切换。
- 导出：96×48 PNG 与 9,216 字节 RGB565 文件，逐像素解包对比无差异。示例为 sample-frame.png 和 sample-frame.rgb565。
- 移动端：390×844 视口，无横向溢出；使用 Chromium 的真实多点触摸输入通道验证同时向右移动与跳跃，松开后两个按钮均释放。
- 全屏：手机尺寸下触摸操作、暂停、重新开始与退出；桌面全屏进入和退出。
- 性能：同一测试浏览器，灯珠遮罩优化后，96×48 约 58 FPS，192×96 约 60 FPS。实际性能随设备和浏览器变化。
- 服务：主页与模块正常，错误编码 URL 返回 400，相邻项目路径返回 404。
- 复核：独立代码审查发现并修复移动端全屏操作缺失，其余未发现重要问题。

未验证真实 LED 硬件、外网部署和 iOS Safari；这是独立浏览器 demo，原始 RGB565 帧为后续设备集成入口。
