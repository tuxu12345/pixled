# LED Arcade · 霓虹疾行

基于 LED Studio 的独立第四个 demo。原创横版跳跃射击游戏，三段关卡，所有角色、场景、生命、得分与结算都实际绘制在 LED 点阵内。

## 启动

安装 Node.js 后，双击 `start.bat`，打开 http://127.0.0.1:8142 。也可以运行：

```sh
npm start
# 或指定其他端口
node server.mjs 8143
```

无需 npm install，无构建步骤、外部字体或图片依赖。可将本目录作为静态网站独立部署；所有前端资源都使用相对路径。不支持直接用 file:// 打开 ES 模块。

## 玩法

打开即自动演示，三关循环播放。点击「开始游戏」、按 Enter 或方向键接管。自动演示也遵守普通玩家的物理和碰撞规则。

| 操作 | 键盘 |
| --- | --- |
| 左右移动 | ← → / A D |
| 跳跃、空中二段跳 | Space / W / ↑ / K（释放后再按） |
| 连续射击 | 按住 J / X |
| 暂停或继续 | P / Esc |
| 重新开始 | R |
| 全屏 | F |

手机和平板显示多点触控按钮，可同时移动、跳跃与射击。切出窗口自动暂停手动游戏，防止丢失生命；按 P 或触屏按钮继续。

向右抵达信号门完成关卡。普通守卫 2 次命中，最终首领 14 次命中。能量 +50，守卫 +100，首领 +1000，完成关卡每条剩余生命 +200。三条生命，受伤后 1.8 秒保护，掉落后回到自动保存的安全地面。每关最高分保存在当前浏览器，自动演示不计入记录。关卡卡片可随时选择；通关后点「下一关」。

## LED 与导出

- 原生 96×48 / 128×64 / 192×96，较大分辨率显示更大的世界范围，角色仍按灯珠绘制。
- RGB565 量化，15–100% 亮度，0–80% 辉光，LED 灯珠 / 纯净像素，可选扫描线。
- PNG 为当前帧的原生分辨率图像，包含游戏 HUD 和亮度效果，不含显示器外壳或模拟辉光。
- `.rgb565` 是无文件头的 RGB565 大端字节流，按从左到右、从上到下排列，每像素 2 字节。96×48 = 9,216 字节。尺寸包含在文件名中，颜色与 PNG 一致。
- 这是浏览器内可玩的虚拟 LED demo。尚未连接真实硬件；原始帧可以交给设备驱动，真实互动还需要按硬件协议接入传输和输入。

## 结构与验证

`js/game.js`：不依赖 DOM 的固定步长模拟、关卡和自动操作；`js/render.js`：原生像素场景；`js/app.js`：输入、主循环、设置和导出；`js/led/`：buffer.js 复制自邻近 LED Studio，display.js 在原有接口和显示原理上改为缓存灯珠遮罩，避免每帧生成上万个渐变。运行时不依赖原项目。原来的拼豆、LED Studio、MiniLED Studio 不作修改。

```sh
npm test
```

测试覆盖落地、二段跳、平台、射击、伤害保护、掉落重生、收集、通关、首领门锁、重置，以及三关自动游玩的真实可通关性。设计和实现清单见 `docs/`。
