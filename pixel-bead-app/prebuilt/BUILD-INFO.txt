安装
  常规（车机 / 一般手机）：
      adb install -r pixelbead-debug.apk

  MIUI / HyperOS 上 adb install 会被拦（INSTALL_FAILED_USER_RESTRICTED），两条路：
  1) 开发者选项里打开「USB 安装」，再重试 adb install
  2) 绕过去 —— 不用 adb install，走安装会话：
         adb push pixelbead-debug.apk /data/local/tmp/pb.apk
         adb shell pm install-create -r -t -S 1295445
         adb shell pm install-write -S 1295445 <sessionId> base /data/local/tmp/pb.apk
         adb shell pm install-commit <sessionId>
     仓库里的 tools/install-on-phone.ps1 把上面这串自动化了，还带断线重试。
