三者的关系（容易混）：
LED Studio（点阵屏） Mini-LED Studio（背光） 像素 = 灯珠本身 像素 = LCD 透光率 × 背光 间距 3~5mm，肉眼可见 间距 0.1~0.5mm，看不见 看"图案怎么显示" 看"分区怎么给光" ↑ 拼豆工坊（拼豆） 像素 = 一颗豆子，间距 5mm 产物既能拼实物，也能直接上点阵屏

拼豆和点阵屏是同一件事的两面：都是离散格子 + 有限色板，图案格式通用。 LED Studio 的「拼豆图案」上屏功能会直接读取拼豆工坊的图案库。

本地跑：进任意子目录执行 node server.mjs <端口>。 必须用本地服务打开，不能双击 index.html —— 浏览器禁止 file:// 下加载 ES 模块。
